## 2. 本次实际验证

完整结果：[串行验证记录](<../test-results/viewing-implementation-20261113-1923/validation.json>)。

- **24项预热纯模块用例通过**：20分钟假时钟、长集休眠/片尾复核、短TTL成功维护超过4次、真实失败上限、签名地址变化、晚ACK、单槽及12秒租约边界。
- **19项核心纯模块用例通过**：缓冲拖动零RPC、失败重试、取消ACK、跨组件同片命令顺序、历史交接与同步保存、原因码、最新会话ACK、MSE/MMS源绑定。
- **5项实际活动hook模型用例通过**：执行当前hook代码，但使用最小生命周期模型，不启用React DOM/浏览器；覆盖新源ACK等待、主动暂停、晚play Promise、活动门控。
- **TypeScript全src＋tests的noEmit静态检查通过**。
- **5个Rust文件rustfmt语法/格式检查通过**；新增4个Rust定向测试仅落盘，**本轮未编译、未执行**。
- **git diff空白检查通过**，按单次CRLF规则处理，未改全局Git配置。

一轮完整串行耗时约15秒：纯模块合计约1.3秒、类型检查约7.7秒、Rust语法格式约4.6秒、空白检查约1.4秒。这是墙钟时间，不是CPU占用采样。此前有轻量定向检查和两次静态检查迭代；首次发现ES2021缺少Object.hasOwn，已改用兼容写法；Rust首次仅格式差异，限定文件格式化后通过。

验证调度采用一个父进程和一个子进程串行运行，子进程尽力设为较低优先级：纯模块V8堆上限128MiB，类型检查256MiB，父96MiB。**堆上限不是进程总RSS硬上限**，未测得的CPU降幅/内存降幅不作承诺。

可重复的轻量入口：[串行验证脚本](<../scripts/validate-viewing-light.mjs>)。

```powershell
node --max-old-space-size=96 scripts/validate-viewing-light.mjs
```

此入口没有cargo、Vite、浏览器、媒体服务或上游调用。旧的“复现旧缺陷”分析探针保持历史原样，修补后不应把它当验收脚本运行。
